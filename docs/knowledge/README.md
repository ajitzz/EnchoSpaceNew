# ENCHO Engineering Knowledge Base (EKB)

This directory serves as the permanent memory of ENCHO.
Every difficult engineering discovery made during the lifetime of ENCHO must be documented here.
Future AI sessions must read these documents before modifying the related subsystem.
Never allow important engineering knowledge to exist only in chat history.

## Knowledge Entry Format
Every entry must use this structure:

```markdown
## Knowledge ID
KB-XXXX

---
### Topic
Short title

---
### Problem
Describe the issue.

---
### Symptoms
Observable behaviour.

---
### Root Cause
Evidence-based root cause.

---
### Investigation
How the issue was diagnosed.

---
### Solution
Permanent solution.

---
### Verification
How the fix was confirmed.

---
### Regression Risks
Potential future breakage.

---
### Related Files
List affected files.

---
### Related ADR
ADR reference.

---
### Related Incident
Incident reference.

---
### Last Verified
Date

---
### Status
Draft / Verified / Production Verified / Deprecated
```
