# Meta Campaign Engineering Best Practices
- **Audience Size**: Aim for broad audiences (2M+) when using conversion objectives to allow Meta's ML to optimize.
- **Budgeting**: Daily budget should be at least 5x to 10x the Expected Cost Per Lead (CPL) to exit the learning phase (50 conversions in 7 days).
- **Creative Diversity**: Provide at least 3 distinct images and 2 distinct ad copies per ad set.
- **Aspect Ratios**: 1:1 for Feed, 9:16 for Stories/Reels, 16:9 for In-Stream Videos.
