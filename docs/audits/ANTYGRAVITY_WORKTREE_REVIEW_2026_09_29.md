- Own-trip read endpoints and foreign-user denial in `staysCommerceRouter.ts`/`staysCommerceEngine.ts` are useful *design slices*, provided they query canonical booking data, do not leak cross-tenant existence, and preserve existing routes. Review eligibility must match the approved fulfillment/refund policy and the existing review writer, not only a GET preflight.

The observed implementations are not accepted: they must be integrated with the canonical outbox, actual provider capability/readback and released strategy bindings rather than parallel demonstration services.
