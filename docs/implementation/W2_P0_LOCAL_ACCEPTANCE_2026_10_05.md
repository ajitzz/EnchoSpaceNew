**Authority accepted locally:** The existing `stays_quotes` table is extended by local-only additive migration `050_accepted_offer_itinerary_quotes.sql`. A server-created, immutable accepted-offer quote binds one exact W1 accepted offer revision, canonical listing and room, dates, guests, INR nightly amount, room subtotal, principal, request identity, source hash and expiry. It does not assert tax or payable total. The mounted hold POST accepts the quote identity, not caller room/date/money authority. One held PostgreSQL transaction rechecks the quote, current accepted revision, principal, expiry and live all-night inventory before binding and committing one temporary `booking_holds` row. It preserves durable idempotent replay and the existing hold TTL. A superseded offer requires a fresh quote before a new hold (founder decision RMD-057). Historical pre-050 holds remain readable and releasable by their holders. The Guest UI says “temporarily held,” not booked, confirmed or paid.

Runtime readiness rejects BYPASSRLS, ownership or inherited ownership of protected tables, all-data roles, direct W1 offer-table grants and missing quote/function grants. Migration 050 fails atomically if that restricted role is absent or unsafe. Existing owner-backed general web access cannot substitute for this role. Applied migration bytes 049 and earlier are unchanged. Migration 050 was applied only to disposable PostgreSQL. No primary Neon mutation, external provider action or production deployment occurred.
