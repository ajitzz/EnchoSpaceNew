## Review and update protocol

1. Verify current source/artifact identity and the original criterion before making a disposition.
2. Attach exact mounted route/worker, canonical database authority, UI journey and relevant evidence references. Record inapplicable dimensions with reviewer rationale; do not leave them silently blank.
3. Separate local unit proof, integrated disposable PostgreSQL/browser proof and authentic external evidence. Tests containing mocks cannot fill a stronger evidence slot.
4. Record independent reviewer identity and immutable decision evidence. Implementation alone does not advance acceptance.
5. Validate the register using `node scripts/cr1/verify-reacceptance-register.mjs`; invalid criteria, IDs, missing references or invented acceptance block the check.
6. Changing a controlling criterion requires an explicit approved decision; update source and register together without erasing prior evidence.
