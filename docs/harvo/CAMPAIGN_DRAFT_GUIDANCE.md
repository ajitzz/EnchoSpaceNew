# HARVO — evidence-grounded campaign drafting

Date: 13 September 2026. Scope: bounded AI drafting assistance and an explicit host review/apply component. Root owns router/runtime integration and mounting; this owner adds isolated guidance modules, component and tests.

## Verified context and impact plan before code

The existing `CampaignAiReviewer` evaluates an already-saved revision; it does not guide a host through writing the initial Search assets. `readListing` already provides server-read ownership, publication, title, city, description and approved-media evidence. Root has implemented the shared database-backed five-per-hour `CAMPAIGN_GUIDANCE` request budget. Guest checkout/legal and provider launch gates are unchanged.

Add `CampaignDraftGuidance.suggest(listing, provider, actor)` using configured Gemini only. Validate the server-read listing owner/publication, exclude money/media URLs/contact information from model input, bound prompt/output/deadline, require structured JSON and validate every returned copy/keyword item against exact source evidence. To limit invented amenities or offer claims, use extractive complete source phrases plus a small set of neutral booking calls to action. Reject unsupported wording, guarantees, contact leakage and price/discount claims. The output is drafting help requiring human accuracy review, not policy approval, targeting validation, a performance prediction or an automatic campaign revision.

Google suggestions must satisfy current Search headline/description lengths and counts and only EXACT/PHRASE keyword match types. Meta receives copy suggestions and no Search keyword or audience mutation. No budgets, dates, country/resource IDs, billing, rights confirmation or approval state may be produced. Missing configuration, timeout or malformed/ungrounded model output returns unavailable with no replacement advice.

Add a pure shared response contract and `CampaignGuidance` component using existing authenticated requests and marketing styles. Responses are bound to the selected property/provider. Requests abort and results reset when selection changes. The host reviews source citations, explicitly confirms accuracy and then applies copy to the local editor. The root mount must preserve other fields and require saving/evaluation of the revised draft. No automatic save, finance action or publication occurs.

No schema/migration change. UI regression risks are stale results, accidental form submission, overwriting unrelated fields and presenting generated text as verified fact. Tests cover ownership, limits, absent credentials, timeout, hostile/unsupported output, evidence identity, exact match types, no financial authority and explicit UI apply. Rollback removes the component and route while retaining existing manual drafting and AI review.

Primary references: [Gemini structured output](https://ai.google.dev/gemini-api/docs/structured-output) supports JSON-schema responses but does not make semantic claims true; [Google responsive Search ad creation](https://developers.google.com/google-ads/api/docs/responsive-search-ads/create-responsive-search-ads) defines asset requirements. Model selection remains explicit configuration, not an invented default.

## Verification

Implemented `src/lib/marketing/guidance.ts`, the pure `guidanceContract.ts` schema and `components/marketing/CampaignGuidance.tsx`. Root wires the authenticated route and editor mount. The shared request accepts only listing ID and provider. The server repeats owned/published checks, hashes the full listing evidence and sends bounded title/city/complete description phrases to the configured model. Price/discount claims, contact text, instructions and media URLs are excluded. A generated item must contain its exact cited complete source phrases and may add only neutral booking connective words. This conservative constraint limits creative flexibility; it is not proof that host-supplied property claims are true. Manual accuracy and provider review remain required.

Google guidance supplies 3–15 headlines at most 30 characters, 2–4 descriptions at most 90 characters and EXACT/PHRASE keywords. The model is asked for a smaller useful starting set. Meta supplies copy, no keywords, and headlines fit the existing 80-character editor. The UI presents source disclosures, an unchecked accuracy confirmation and a copy-only apply action; property/provider changes abort requests and discard prior results. Applying does not save the campaign, confirm media rights, alter targeting/money or bypass a new assessment.

The final isolated guidance run passed **48 tests**: 39 source/model-contract cases and nine interactive jsdom component cases. Command: `npx vitest run --config vitest.marketing-m1.config.ts src/test/harvo/campaign_draft_guidance.test.ts src/test/harvo/campaign_guidance_ui.test.ts`. Focused strict TypeScript checking passed for both modules/component and tests. Tests inject model responses and never read AI credentials or call Gemini. Root independently verifies authenticated route budgets, browser layout and editor integration. Actual configured model quality, advertiser policy acceptance and improved booking conversion still require measured acceptance; generated source-grounded copy alone cannot establish them.
